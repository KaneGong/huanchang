# 幻场中英文界面范围评估

2026-10-14。用户询问工作量，尚未授权完整英文界面制作。

结论：中等规模的跨页面改动，不需要重做视觉或重写网站；当前文案散布在10个前端模块及Python校验/错误/邮件中，不能只改首页或依赖浏览器即时翻译。

## 推荐顺序

1. 本轮完成中英文GitHub介绍；网站以中文完成云端发布验收。
2. 发布适配稳定后，抽取界面词条到zh-CN/en资源；统一语言读取、保存、格式化与回退策略。数据的内容形式、合作选项等内部值保持稳定，显示名称按语言切换；不要把中文枚举翻译后写回业务数据。
3. 覆盖发现、作品详情、创作者、发布与个人编辑、评论、收藏/点赞、消息、动态、注册/登录、账户设置、管理、平台说明及邮件；服务端错误提供稳定标识与对应译文。
4. 验证英文长度、移动排版、无障碍标签、日期/数量、空状态、错误/加载状态；检查两种语言下的核心双账户流程。

工作量预估（实施判断，非经过实测的工期承诺）：仅界面与系统邮件双语大约3–6个有效开发工作日，取决于词条数量、英文文案确认和回归问题；不会因此自动增加内容翻译、多语言搜索或海外运营能力。完整国际版还需单独处理搜索、政策、推广、内容组织与目标地区访问体验。

## 产品边界

- HUANCHANG作为英文品牌保留；不另起英文名。
- 用户作品、作者介绍、评论、私信保持原文，不自动翻译；创作者可自行写双语内容。
- 英文界面可查看中文作品；若将来增加翻译，应标示机器翻译且保留原文。
- 首次语言根据浏览器偏好建议，用户可切换并保留选择；不强制按所在地判断语言。
- 首页字体和持续星光需验证拉丁字母采样、长短行、断行；保留已认可的视觉节奏。
- 未决定上线前做全站双语，不将英文按钮或半成品语言切换加入主站。
