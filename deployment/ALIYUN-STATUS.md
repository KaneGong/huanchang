# 阿里云部署状态

更新：2026-10-15。幻场 / AIGC Yard 计划以 aigcyard.com 为主域名，现阶段尚未完成正式公网切换。

## 已完成的内部验收

上海 ECS、PostgreSQL 17、Gunicorn/systemd 与同地域私有 OSS 已完成上一轮内部部署与数据迁移验收。注册、发布、图片直传与再次裁切、评论、双账户私信及应用重启后的持久性已验证。源数据表内容与图片哈希已核对。上述结果是迁移验收记录，不是持续在线或容量保证。

图片通过受限 ECS 实例角色取得临时凭证，使用短期签名上传和读取；不使用公开读桶。网站目前仅供受控内部访问，未开放正式公网入口。

ICP备案于2026年10月14日提交，所涉域名为 aigcyard.com；提交不代表审核通过，aigcyard.cn 不在此次申请内。

## 上线前仍需完成

1. 完成备案审核及要求的核验。
2. 在切换窗口停止旧环境写入，最终同步新增数据与图片，并保留回退副本。
3. 配置域名、HTTPS、正式安全 Cookie 与可信代理，关闭内部预览模式。
4. 通过真实国内手机和 Wi-Fi 网络验收访问、注册、上传、发布与交流流程。
5. 小规模真人试用后，根据实际故障和使用情况决定扩大范围。

原 Vercel/Supabase 测试环境仍保留；用户曾报告国内手机直连失败，因此不作为国内公开可用的验收结果。当前邮件验证和邮件找回未启用，账户需保存恢复码。定时备份与外部告警尚未建立。

本次 GitHub 更新同步部署信息；阿里云运行适配仍在受控部署中，尚未随此次文档提交发布。仓库现有 Vercel 指南与容器模板各自保留，不应直接当成阿里云生产部署步骤。服务器地址、账号资料、密钥、真实用户内容、备案材料与私密备份不随说明公开。
