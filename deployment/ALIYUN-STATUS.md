# 阿里云部署状态

更新：2026-10-15。幻场 / AIGC Yard 香港试用站已开放：https://trial.aigcyard.cn/ 。浏览无需登录，注册后可发布与交流；当前没有邀请码限制。

## 当前运行环境

香港轻量应用服务器使用 PostgreSQL 17、Gunicorn/systemd、Nginx 和同地域私有 OSS。HTTPS 已启用，内部预览模式已关闭；应用与数据库仅监听本机，登录使用 Secure/HttpOnly 的 `__Host-` Cookie。图片使用限于目标私有桶读写的程序凭据和短期签名，不开放匿名图片读取。

公网注册、登录、图片上传与显示、防覆盖和跨账户权限、发布、评论、双向私信检查通过，临时验收账户及内容已清理。最终源备份与迁入数据一致；香港数据库和图片的加密备份已在独立 PostgreSQL 环境中恢复并核对。

上海服务器到香港站的 HTTPS 健康请求成功，一次观测约 0.18 秒；这不能代替手机体验、持续可用性或容量验收。用户反馈手机可以打开且加载速度不慢；未确认代理设置及 Wi-Fi/移动数据两种网络，登录、上传和裁切等完整手机操作仍待体验。图片上传已通过公网 HTTP 操作验证；浏览器文件选择与裁切仍待真实手机复验。

## 上海与备案

上海 ECS 与同地域私有 OSS 保留为后续迁回目标，目前仍为内部环境。计划正式主域名为 aigcyard.com；该域名的 ICP 备案于2026年10月14日提交，最新审核结果尚未重新核实。aigcyard.cn 不在此次备案申请中，不宣称已备案。

迁回时需先停止香港写入，备份并最终同步新增数据和图片，在上海核对恢复、权限和页面，再切换域名。已验证备份恢复能力，不承诺无需切换窗口或任何情况下零中断。
