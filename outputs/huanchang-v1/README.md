## 数据和恢复

新数据库：项目根目录下 `work/huanchang/huanchang.sqlite3`；上传图片：`work/huanchang/media/`。不要只复制前端文件而漏掉这两处。

```sh
python3 scripts/huanchang_backup.py
```

备份位于 `work/huanchang-backups/`。数据库通过 SQLite 一致性备份读取，备份中的登录会话被移除；原站点会话不受影响。备份仍含用户内容与账户密码哈希，应保存在私有位置，不上传到公开仓库。

恢复时先停止服务，并另存当前数据库和媒体目录。将选定备份中的 `huanchang.sqlite3` 和 `media/` 放回 `work/huanchang/`，再启动服务。恢复后账户需重新登录。恢复工具 `scripts/huanchang_restore.py` 只恢复到尚不存在的新目录，校验数据库和上传图片。已完成本机恢复、登录与内容核对；正式部署主机仍须演练。备份同时清除邮件验证码。
