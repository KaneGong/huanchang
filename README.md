## 让想象成形，让彼此相遇。

**幻场 / AIGC Yard** 是服务于 AIGC 创作者、欣赏者与有创作需求的人们的作品与交流社区，让作品被发现，也让不同专长的创作者找到彼此、开启共同创作。

这里可以是用 AI 造梦的地方，也是寻找某个梦、某种风格、某位同行者的地方。我们希望连接的不仅是作品与观看者，还有想法与能力、欣赏与交流，以及愿意一起把事情做出来的人。

从一个角色、一段故事、一幅画面或一首声音作品出发，发现作者如何创作，再开始一次有具体来由的交流。

> 分享 AI 创作，发现心动的作品，找到愿意一起做事的人。

## 从一个人的灵感，到一群人的作品

一件好作品，可以由不同的创作能力共同完成：有人擅长编剧与故事，有人擅长概念图、角色与场景，有人擅长导演与风格把控，也有人擅长视频制作、剪辑与特效。

幻场希望成为这些能力相遇的地方。通过作品、创作说明与个人主页，认识彼此的专长，表达自己希望一起做什么，再围绕具体想法开始交流与合作。从剧本到视觉设定，从制作到后期打磨，让各自的优势连接起来，一起创造更完整、更出色的作品。

## 我们希望解决什么

| 对于谁 | 常见的断点 | 幻场的做法 |
| --- | --- | --- |
| 创作者 | 作品散落在不同平台，别人难以理解自己的方向与贡献 | 用作品集、创作说明、代表作和个人主页呈现持续的创作能力 |
| 寻找创作伙伴的人 | 有剧本、视觉设定或制作能力，却缺少完成作品所需的其他专长 | 通过作品与主页认识互补的伙伴，在介绍中说明希望一起做什么，再围绕具体想法交流 |
| 欣赏者 | 看过一张好图，却记不住作者，也不知道下一步去哪找 | 从作品进入作者主页，收藏、点赞并沿主题继续发现 |
| 有需求的人 | 只看成果难以判断作者是否适合，也不知如何开启联系 | 查看作者的创作方向与交流偏好，从具体作品发起私信 |
| 学习者 | 看到了结果，却看不到尝试、取舍与方法 | 在教程与经验中阅读过程，围绕作品展开讨论 |

这些是产品希望解决的问题；是否有效，需要通过真实使用与反馈持续验证。

## 可以在这里做什么

### 发现创作

- 按图像、视频、声音、文字、互动与 3D 浏览内容，支持搜索、筛选、精选与最新排序。
- 从角色与世界、故事、形态与感官等主题进入创作；角色设定、剧本等作为主题或标签表达。
- 阅读精选看点和创作说明，了解作品的表达、制作方法与作者贡献，发现自己想学习或一起尝试的方向。
- 收藏喜欢的内容，点赞表达欣赏，回到私人列表继续浏览。

### 呈现作品，也呈现自己能带来的能力

- 发布作品或教程与经验，说明本人贡献、AI 参与、创作过程、交流方向与使用边界；共同创作的作品可以在说明中记录伙伴的分工与贡献。
- 图片最多 8 张，单张最多 20 MB、单篇合计最多 60 MB；支持说明、阅读顺序、展示图裁切与编辑。
- 视频、声音、互动与 3D 支持外部作品链接；当前不提供用户视频/音频文件托管。
- 设置头像、主页展示图、介绍、创作方向、代表作和交流偏好，说明自己擅长编剧、概念设计、导演、视频制作、剪辑或特效中的哪些环节，以及可以一起做什么。
- 管理草稿、已发布与已移除内容；本人可查看作品浏览、点赞和收藏数量。

### 找到互补的伙伴，开始共同创作

- 从感兴趣的作品进入作者主页，结合代表作、本人贡献与创作方向，了解对方能为共同创作带来什么。
- 在作品的交流方向或个人介绍中表达已有的想法、希望完成的作品与缺少的伙伴，例如“已有短片剧本，希望找角色设定与分镜创作者一起尝试”。
- 用评论讨论一个具体问题，或附上作品发起私信，说明自己的专长、需要的帮助，以及想一起完成什么。
- 接收方选择是否回应，再由双方交流创作方向与分工。首版提供认识伙伴、发起合作和持续沟通的入口；共同制作的安排由参与者自行商定。

### 让交流有上下文，也有选择

- 围绕作品评论、回复和讨论，通知定位到具体内容。
- 私信可附带作品，让接收方知道交流的来由；陌生联系由接收方选择回复或关闭。
- 查看历史消息、未读动态与私信，屏蔽不希望继续的交流，举报需要处理的内容。
- 管理员可处理举报、内容可见性与账户状态。

### 保护账户与编辑过程

- 账号名与密码注册，邮箱选填，暂不要求手机号。
- 配置邮件服务后，可验证邮箱并找回账户；也提供恢复码。
- 编辑草稿保留；登录失效时提示重新登录并返回原编辑页面。
- 私信、私人收藏与账户邮箱不公开展示；服务端校验访问与修改权限。

## 我们的设计原则

**作品优先。** 给不同形式的创作合理的展示空间，让作品成为交流的起点。

**看见人，也看见过程。** 创作贡献、判断过程、作者方向与精选理由共同帮助理解作品。

**让不同专长连接起来。** 编剧、概念与角色设计、导演、制作、剪辑和特效可以各有所长。用实际作品和清晰的能力说明帮助彼此判断是否适合共同创作，尊重每个人的贡献。

**联系要有来由。** 围绕具体作品和具体想法发起交流，尊重接收方的回应选择。

**让合作从具体想法开始。** 清楚表达已有内容、需要的伙伴和希望一起完成的作品，让欣赏和交流有机会发展为共同创作。

**先把基础体验做好。** 首版免费提供发现作品、呈现专长、寻找伙伴与沟通的入口。暂不加入交易、抽佣、自动撮合、双方确认卡或私密协作空间。

视觉采用暖白、深绿与克制的黄绿点缀，结合作品墙、清晰的阅读层级和持续散聚的标题星光。减少动态设置下保留清晰的静态文字。

## 运行与部署

本机预览使用 Python 标准库，无需安装云端依赖：

```sh
python3 huanchang_server.py --demo
```

访问 `http://127.0.0.1:8790/#/works`。`--demo` 仅用于本机体验示例身份；正式环境关闭示例登录。

```sh
python3 -m unittest tests.test_readiness -v
```

当前试用路线：**香港轻量服务器 → PostgreSQL17＋香港私有 OSS**，已开放 HTTPS 试用。上海 ECS 保留为备案通过后的迁回目标。维护、验收范围与后续切换见 [阿里云部署说明](deployment/ALIYUN-STATUS.md)。邮件服务尚未启用，请保存恢复码。

原测试路线：**GitHub 管理代码 → Vercel 提供页面与接口 → Supabase 保存数据库和图片**。

云端适配保留现有账号名与选填邮箱方式，使用私有 PostgreSQL schema、服务器端权限校验和私有图片桶；图片通过授权直传，避免高清图片经过函数请求体。

部署与验证步骤见 [云端部署指南](deployment/VERCEL-SUPABASE.md)。不将账户数据库、真实上传、密钥或开发过程备份提交到仓库。

## 交流与贡献

欢迎分享你在寻找伙伴和共同创作中遇到的具体困难：是否能看懂对方的专长与贡献，是否容易说明自己需要什么，以及交流后还有哪些断点。这些反馈会帮助我们判断后续合作功能该解决什么问题。

也欢迎提供可复现的问题、清晰的交互反馈和改进建议。请附页面、操作步骤、预期结果和实际结果；避免上传私人消息、邮箱、验证码或账户数据。

开发贡献与检查见 [CONTRIBUTING](CONTRIBUTING.md)，安全问题处理见 [SECURITY](SECURITY.md)。
